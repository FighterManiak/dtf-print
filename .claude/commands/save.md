---
description: 변경사항을 GitHub에 저장 (commit + push)
argument-hint: [저장 메시지]
---

현재 git 저장소의 모든 변경사항을 저장(백업)해줘. 다른 컴퓨터에서 이어서 작업할 수 있도록 GitHub에 올리는 것이 목적이야.

절차:
1. `git status`로 변경 내용을 확인
2. 변경된 파일을 모두 스테이징 (`git add -A`)
3. 커밋: 아래 "저장 메시지"가 있으면 그대로 쓰고, 비어 있으면 변경 내용을 한국어로 간결하게 요약해서 커밋 메시지를 작성
4. `git push`로 원격(GitHub)에 업로드
5. 완료되면 무엇이 저장됐는지 한 줄로 알려줘

저장 메시지: $ARGUMENTS
